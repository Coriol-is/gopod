# Connected services and recurring work

Read `/workspace/chat/INTEGRATIONS.md` first (it exists in the owner chat only).
It explains how to see which tools you have, propose recurring actions with their
cost, ask for the schedule and notification time, and create them as scheduled
tasks through `/workspace/chat/SCHEDULING.md`. Do not assume tool names and never
create a task without a yes from the owner.

The guide is embedded and seeded by gopod, and the same pointer is in the system
prompt for both providers; this optional skill mount (Claude only) is additional
discoverability, not a requirement.
