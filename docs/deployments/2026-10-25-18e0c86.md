# Deployment evidence — background extraction starvation

## Payload and checks
Application commit `18e0c866909e011eae265a80f0446d1b97746b7e` (PR #43).
An unbounded Codex fresh extraction held the chat execution slot, delaying both
private topics. See [incident](../incidents/2026-10-25-background-extraction-starvation.md)
and D033. The fix adds a one-minute RunFresh budget and same-chat foreground
preemption, cancellable buffered process cleanup and context-preserving canceled
compaction. Chat-wide provider scope and serial per-chat execution are unchanged.

Independent review clean at 5487fae; PR test run 40216380271 (42s) and Sonar green
before squash merge. Local build/vet/full tests passed; runner/Telegram/queue
race suites passed 9.486/16.306/1.590s. Regressions include background/foreground
cleanup ordering, caller deadline, other-chat independence, priority and canceled
compaction retaining session/counters. Existing cleanup failures/escaped process
groups are explicit limits; no exactly-once or quiet-hours completion claim.
