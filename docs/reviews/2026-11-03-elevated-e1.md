# CP-038 E1 — separate profile and guard

Owner approved D059: deny transitions involving elevated, preserve D044's
ordinary foreground/task recycling. The ordinary builder fixture and digest
were committed in `43027d3` before the implementation.

Implemented a separate root/host-namespace builder, fixed host/socket/workspace/
provider-state mounts, positive resource caps and reserved policy identity.
No ordinary mounts, arbitrary environment forwarding or managed-runtime toggle
is inherited. The managed role planner explicitly rejects elevated.

Elevated ensure accepts the Docker facade independently of managed tasks,
compares requested config digest, inspected configuration and immutable image,
and refuses drift, stopped containers or different roles without recycling.
PID/network/IPC modes are read from Docker; only ordinary default/bridge network
and private IPC normalize to empty. Existing builder bytes/digest stay unchanged.

Validation: build, vet, full test suite and full runner race suite passed.
Independent source review and a separate focused test run passed. Coverage
includes both role-boundary directions while running/stopped, unlabelled
containers, namespace drift, self-consistent but wrong requested configuration,
invalid paths/resources, and ordinary role-planner rejection.

No elevated command, session manager, privileged Docker probe or deployment is
included. E2/E3 must add journal-before-exec and reserved-folder exclusions;
E3/E4 must implement the owner-required warning/confirmation/teardown dialogs.
