# CP-038 E2 — reserved identity, context and exec journal

Dedicated lifecycle/native-context/transcript/exec tables reconcile CP-038 with
P1 without registering elevated or relaxing ordinary scope checks (D060).
One active session and session-ID guarded writes prevent late results from
rewriting reopened state. Provider native context persists only in elevated's
own table, independently of ordinary legacy/durable mapping mode.

Registration, task creation, ordinary builders and scope snapshots refuse the
reserved folder; old reserved registrations are counted/skipped during P1
adoption. Bootstrap rejects symlinks and nonempty unmarked old state, creates
only workspace/native homes and no IPC namespace. Historical registered or
retired namespace ownership prevents opening a host session. Idle cleanup skips
this reserved folder.

Journal intent commits before the callback can exec; write failure prevents
execution, settlement failure prevents result publication. Argv is individually
redacted, JSON encoded then capped at 4096 UTF-8 bytes with an explicit truncation
flag. Exit -1 means unknown host-call outcome, not process-death proof. A closed
session cannot append transcript, native context or new exec intent.

Build/vet/full tests and store/runner race suites passed. Independent source
review found a legacy adoption skip gap; it is fixed with a regression proving
one reserved row skipped and the owner context migrated. Focused tests were
independently rerun. Backup row-count coverage includes all four new tables.

No production manager/caller yet. E3/E4 must serialize operations, prove runtime
quiescence before reopen, implement host-rendered warning/confirmation/markers,
and fence queued or recovered input. Data-row closure alone is not a teardown.
